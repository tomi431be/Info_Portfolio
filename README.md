# 💻 Hardware vs Software

Un petit jeu éducatif permettant d'apprendre à différencier le **hardware** du **software**.

Le joueur doit déterminer si un élément informatique appartient au matériel (**hardware**) ou aux logiciels (**software**).

---

## 🎮 Jouer

Le jeu contient 15 questions.

Pour chaque question, deux choix sont proposés :

- 🖥️ **Hardware** : élément physique que l'on peut toucher
- 💾 **Software** : programme, application ou système informatique

Une explication est affichée après chaque réponse afin de permettre au joueur d'apprendre de ses erreurs.
